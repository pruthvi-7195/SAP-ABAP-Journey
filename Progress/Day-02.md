## ⭐ Most Important Concepts

### TYPES

Creates a type/template.

### DATA

Creates an actual data object.

### Structure

Represents one logical record.

### Work Area

Used to hold/process one record.

### Internal Table

Stores multiple records.

### APPEND

Adds a record to an internal table.

### LOOP AT

Processes internal table records.

---

## 🧠 Important Mental Model

TYPES
↓
Template

DATA ls_data TYPE lty_data
↓
One record / Work Area

DATA lt_data TYPE TABLE OF lty_data
↓
Multiple records / Internal Table

APPEND
↓
Add record

LOOP AT
↓
Process records
