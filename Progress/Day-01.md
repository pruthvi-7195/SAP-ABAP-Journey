## 🧠 Key Learnings

- SAP is an enterprise software platform.
- ERP integrates business processes.
- ABAP is SAP's programming language.
- ABAP is used to develop and customize SAP applications.
- DATA is used to declare variables/data objects.
- WRITE is used to display output.
- ABAP programs execute in the application layer.
- SAP GUI is a traditional SAP interface.
- ADT is an Eclipse-based environment for modern ABAP development.
